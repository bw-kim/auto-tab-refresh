# 탭 자동 새로고침

Chrome 120 이상과 Edge에서 사용할 수 있는 탭별 자동 새로고침 확장 프로그램입니다. 아이콘을 누르면 열리는 팝업에서 간격을 정하고 시작하거나 중지합니다.

## 설치

1. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**에서 이 폴더를 선택합니다.
3. 웹사이트 탭에서 확장 프로그램 아이콘을 누르고 간격을 설정한 뒤 시작합니다.

각 탭에서 따로 시작할 수 있으며, 팝업에서 각 탭의 다음 새로고침까지 남은 시간을 확인하고, 하단 목록에서 다른 탭의 새로고침도 중지할 수 있습니다. 탭이 활성화되지 않아도 새로고침을 시도합니다.

## 알아두기

- 30초부터 24시간까지 정수 초·분·시간 단위로 설정할 수 있습니다. 예약은 브라우저나 운영체제 상황에 따라 늦어질 수 있습니다.
- 브라우저와 컴퓨터가 실행 중이어야 합니다. 절전, 페이지 폐기, 브라우저 정책이나 사이트 동작에 따라 지연되거나 중지될 수 있습니다.
- 탭을 닫거나 다른 사이트로 이동하면 해당 일정이 중지됩니다. 브라우저를 재시작하면 안전을 위해 모든 일정이 중지되므로 다시 시작해야 합니다.
- HTTP 및 HTTPS 웹사이트만 지원합니다. Chrome/Edge 내부 페이지는 지원하지 않습니다. 각 브라우저 및 프로필별로 별도 설치와 설정이 필요합니다.
- 새로고침하면 해당 페이지에 입력 중인 내용이 사라지거나 사이트의 작업이 중단될 수 있습니다.
